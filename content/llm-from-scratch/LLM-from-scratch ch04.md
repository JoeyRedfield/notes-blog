# 使用层归一化进行归一化激活

![[image 996.png]]

> 与在批次维度上进行归一化的批归一化不同，**层归一化是在特征维度上进行归一化**。大语言模型通常需要大量的计算资源，训练或推理时的批次大小可能会受到硬件条件或具体用例的影响。由于层归一化是对每个输入独立进行归一化，不受批次大小的限制，因此在这些场景中它提供了更多的灵活性和稳定性。这在分布式训练或在资源受限的环境中部署模型时尤为重要。

层归一化更多是用在多头注意力机制前后，并且计算方差时unbiased=False也就是不使用n-1作为分母，是因为嵌入维度n非常大，实际差异可以忽略。

并且还要注意计算平均值时dim=1或dim=-1是计算列维度的平均值，以获得每行一个平均值，dim=0是计算行维度的平均值，以获得每列一个平均值。

# 实现具有GELU激活函数的前馈神经网络

![[image 998.png]]

> GELU的平滑特性可以在训练过程中带来更好的优化效果，因为它允许模型参数进行更细微的调整。相比之下，ReLU在零点处有一个尖锐的拐角（参见图4-8的右图），有时会使得优化过程更加困难，特别是在深度或复杂的网络结构中。此外，ReLU对负输入的输出为0，而GELU对负输入会输出一个小的非零值。这意味着在训练过程中，接收到负输入的神经元仍然可以参与学习，只是贡献程度不如正输入大。

![[image 999.png]]

![[image 1000.png]]

原来仅仅只是这样先扩张再还原，也能让模型学习到更多内容，原理是允许模型探索更丰富的表示空间。

> FeedForward模块在提升模型学习和泛化能力方面非常关键。虽然该模块的输入和输出维度保持一致，但它通过第一个线性层将嵌入维度扩展到了更高的维度，如图4-10所示。扩展之后，应用非线性GELU激活函数，然后通过第二个线性变换将维度缩回原始大小。这种设计允许模型探索更丰富的表示空间。

# 添加快捷连接（残差连接、跳跃连接）

![[image 1001.png]]

> 快捷连接涉及将某一层的输入添加到其输出中，有效地创建了一条绕过某些层的替代路径。

- 残差连接的关键不是“跳过一些层”，而是让每层学习“增量”并提供“恒等直通路径”，从而显著改善深层网络的优化与信息流动。
- 减少层数能缓解梯度问题，但会损失深度带来的表示能力与性能上限；残差让你既能深又能训，从而通常提升最终表现。

# 连接Transformer块中的注意力层和线性层

![[image 1002.png]]

> Transformer块的核心思想是，自注意力机制在多头注意力块中用于**识别和分析输入序列中元素之间的关系**。相比之下，前馈神经网络则在每个位置上对数据进行单独的修改。这种组合不仅提供了对输入更细致的理解和处理，而且提升了模型处理复杂数据模式的整体能力。

# 小结

1. **层归一化（Layer Normalization）**
层归一化通过对每一层的输出进行标准化，使其具有稳定的均值和方差，从而改善数值稳定性并加速收敛。这在深度神经网络，尤其是大语言模型的训练中至关重要。
2. **残差连接（Shortcut / Residual Connection）**
残差连接通过将输入直接加到后续层的输出上，为信息和梯度提供了一条直通路径，从而有效缓解深层网络中的梯度消失问题，使更深的模型能够稳定训练。
3. **Transformer 块的组成**
Transformer 块是 GPT 模型的核心结构单元，通常由两部分构成：
    - 带因果掩码的多头自注意力模块（Masked Multi-Head Self-Attention）
    - 使用 GELU 激活函数的前馈全连接网络（Feed-Forward Network, FFN）
这两部分均通过残差连接与层归一化进行组合。
4. **GPT 模型的整体结构**
GPT 模型由多个结构相同的 Transformer 块堆叠而成。随着层数和宽度的增加，模型参数规模可以从数百万扩展到数十亿。
5. **模型规模与实现复用性**
GPT 模型具有多种参数规模，例如约 1.24 亿、3.45 亿、7.62 亿和 15.4 亿参数。尽管模型规模不同，但它们可以通过同一个 `GPTModel` 类进行实现，仅需调整配置参数（如层数、嵌入维度和注意力头数）。
6. **文本生成机制**
类 GPT 大语言模型通过自回归方式进行文本生成：在给定输入上下文的情况下，模型逐步预测下一个词元的概率分布，并根据该分布选取词元，逐个生成完整文本。
7. **训练的重要性**
在未经过训练时，GPT 模型的参数是随机初始化的，生成的文本缺乏连贯性。这表明，大规模预训练对于模型学习语言结构和生成有意义文本是不可或缺的。
