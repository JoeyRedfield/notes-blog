# 简化的自注意力

RNN对于短文本的处理、分类效果很好，但是对于长文本就不行，以翻译任务为例，有些语言不能逐字翻译，词之间可能会有长距离的依赖，而RNN容易因为距离过长而丢失信息。这种缺陷带来了注意力机制的进步，也就是改进成每个词能够关注到其它词汇，也就是对每个词都有相应的权重。先从没有可训练权重的简单自注意力机制开始学习。

以”Your journey starts with one step”的“journey”为例：

1. 计算注意力分数：先前在ch02已经知道每个词的嵌入向量如何得到，现在就要利用它进行点积计算，~~相关程度越高，点积结果越高~~。计算的方式是You*journey^T, journet * journey^T, starts * journey ^ T…以此类推。
2. 计算注意力权重：把注意力分数归一化就得到注意力权重，这能更好地观察journey与其他词的相关性。这里更建议用`torch.softmax()` , 能很好地避免结果溢出的情况。
3. 用2️⃣计算上下文向量：在得到归一化注意力分数之后，跟每个词的Embedding进行相乘~~，就得到“journey”相对于其他词的注意力权重~~。

![[image 966.png]]

> 用注意力权重对所有词的 embedding 做加权求和，得到一个新的向量，表示“**融合了上下文信息的 journey 表示**”。
> 这是注意力最重要的一步，也是和 RNN 最大的分野：
> 
> - RNN：信息沿时间一步步传
> - Attention：**一次性从所有位置取信息**

### 🔹 1️⃣ 这里其实已经隐含了 Q / K / V

你虽然没写，但你的三步实际上就是：

- Query：journey
- Key：所有词的 embedding
- Value：所有词的 embedding

现在之所以看不出来，是因为：

> Q = K = V = embedding

这正是**“无可训练参数的自注意力”**。

这一点一旦你在脑子里标出来，后面引入

`W_q, W_k, W_v` 会非常自然。

---

### 🔹 2️⃣ 点积“越大越相关”不是普适真理（但你现在这样用是对的）

一个严谨但不否定你的补充是：

- 点积高 ≠ 语义一定相关
- 这里依赖的是 embedding 已经编码了语义结构

也就是说：

> 注意力机制本身不创造语义，只是重新分配已有信息。

这是一个非常重要的“去神秘化”理解。

# 实现带可训练权重的自注意力机制

![[image 967.png]]

## 缩放点积注意力（scaled dot- product attention）

还是基于上一章的思想，只是更进一步：实现可训练的注意力权重。最终目的都是得到更好的上下文向量。首先要区分权重矩阵和注意力权重是两种东西。这里引入了QKV，可以类比数据库中的概念：Q是Query，用于数据库的查询；K是数据库键值对的Key，V则是Value。在数据库，QK配合才能顺利找到Value，这里的计算过程也是类似。

$W_q, W_k, W_v$是需要先初始化的。在上一章我们已经了解了怎么计算单词的嵌入向量x，然后x跟qkv相乘，分别得到查询矩阵Q、键矩阵K和值矩阵V，其中Q和K相乘，得到注意力分数矩阵，需要除以 $\sqrt{d_k}$ 进行缩放（Scaling）。为了避免**点积结果过大，导致 Softmax 函数进入饱和区（梯度极小甚至消失）**，需要对**注意力分数矩阵用softmax进行归一化**得到注意力权重矩阵，然后注意力权重矩阵跟值矩阵V相乘得到上下文向量Z。

- **矩阵运算细节**：Q和K相乘时，实际上需要进行转置操作（$Q \cdot K^T$）

> 当向量维度 $d_k$ 很大时，Q和K的点积结果方差会很大。如果不除以 $\sqrt{d_k}$，Softmax 的输入值会非常大（正负极大值），此时 Softmax 的梯度几乎为 0，导致反向传播时参数无法更新。

### 1. 线性投影（Linear Projection）

输入向量 $x$ 并不是直接用来计算注意力的，而是先通过三个可训练的权重矩阵映射到不同的空间。

- **公式**：
$Q = X \cdot W_q$
$K = X \cdot W_k$
$V = X \cdot W_v$
- **补充**：这里的 $W_q, W_k, W_v$ 就是你提到的“需要初始化的权重”，它们是模型学习的核心部分。

### 2. 计算注意力分数（Attention Scores）

计算 Query 和 Key 的相似度。

- **公式**：$Scores = Q \cdot K^T$
- **直观理解**：就像在数据库中，看你的查询（Query）和索引（Key）有多匹配。点积越大，匹配度越高。

### 3. 缩放（Scaling）—— 关键一步

- **公式**：$Scaled\_Scores = \frac{Scores}{\sqrt{d_k}}$
- **为什么是 **$\sqrt{d_k}$**？**：假设 Q 和 K 的元素是均值为0、方差为1的随机变量，它们的点积的方差会变成 $d_k$。除以 $\sqrt{d_k}$ 可以将方差重新拉回到 1，保证数值稳定性。

### 4. 归一化（Normalization）

将分数转换为概率分布。

- **公式**：$Attention\_Weights = \text{softmax}(Scaled\_Scores)$
- **结果**：每一行的权重之和为 1。这代表了模型在生成当前位置时，对序列中其他位置的“关注程度”。

### 5. 加权求和（Weighted Sum）

根据注意力权重，聚合 Value 向量。

- **公式**：$Z = Attention\_Weights \cdot V$
- **意义**：最终的上下文向量 $Z$，是所有 Value 的加权平均值。关注度高的地方，其 Value 被保留得更多。

## 因果注意力机制

> 在Transformer架构中，一些包括GPT在内的模型通常会在两个特定时间点使用注意力机制中的dropout：一是计算注意力权重之后，二是将这些权重应用于值向量之后。

![[image 968.png]]

在自回归语言建模任务中，自注意力机制在结构上允许每个位置关注序列中的所有 token，如果不加约束，当前位置在训练时会访问未来 token，造成信息泄漏。因此需要引入因果注意力机制。

具体实现上，在计算注意力分数（QKᵀ / √d）后、softmax 之前，使用下三角掩码屏蔽对角线右上方的位置，通常将对应 logits 设为负无穷，使其在 softmax 后的注意力权重为 0。

随后可在注意力权重或注意力输出上施加 dropout，以降低模型对特定位置的依赖，提升泛化能力。

- 因果注意力不是“为了更好效果”，而是**防止必然发生的数据泄漏**
- mask 作用在 **softmax 之前的 attention logits**
- 用 `inf` 而不是 `0`，是为了 **不破坏概率分布**
- dropout 不是“随便一加”，而是**有明确位置和作用对象**

## 多头注意力机制

> “多头”这一术语指的是将注意力机制分成多个“头”，每个“头”独立工作。在这种情况下，单个因果注意力模块可以被看作单头注意力，因为它只有一组注意力权重按顺序处理输入。

![[image 969.png]]

上述图片算是总结了多头注意力机制的内容。

由输入矩阵X跟权重矩阵W_Q, W_K, W_V相乘，得到对应的Q、K、V矩阵；

Q 与 K 做点积得到 scores，经 softmax 得到 attention weights，再乘 V 得到 Z。

在多头里每个 head 都会产生一个 `Z_head`，最后是：

- concat：
$Z=concat(Z(1),...,Z(h))Z = \text{concat}(Z^{(1)},...,Z^{(h)})Z=concat(Z(1),...,Z(h))$
- 输出投影：$Y = ZW_O$

这里输出投影通常写 `W_O` 或 `out_proj`，写“投影 W”建议明确是 $W_O$。

多头注意力则是将Q/K/V最后一维reshape切成num_heads个head_dim，每个head独立做attention得到各自的上下文，拼接heads，再做一次输出投影W

> 必须满足 `d_model(=d_out) % num_heads == 0`，且 `head_dim = d_model/num_heads`。

两种方式本质上是：

4. **多线性层/多 head 分开算**：每个 head 各自一套投影（或各自算 Q/K/V），再 attention，再 concat
5. **单大线性层一次算完**：一次算出全部 head 的 Q/K/V（常见 fused QKV），reshape 分头 attention，再 concat

它们**数学等价**，差别主要是工程效率（更少的 kernel launch、更好的内存访问、更容易融合），不是“算式不同”。

## 给你一版“可直接背下来”的严谨表述（推荐替换你原文）

- 输入 ($X\in\mathbb{R}^{B\times T\times d_{model}}$)，通过线性投影得到
($Q=XW_Q,\ K=XW_K,\ V=XW_V$)，形状均为 $(B,T,d_{model})$。
- 将 Q/K/V reshape 为多头：$((B, h, T, d_{head}))$，其中 $(d_{head}=d_{model}/h)$。
- 每个 head 做：
$(S = QK^\top)$，加因果 mask，
$(A=\text{softmax}(S/\sqrt{d_{head}}))$，
$(Z=AV)$。
- 拼接所有 head 的 (Z) 得到 $((B,T,d_{model}))$，再经输出投影 ($W_O$) 得到最终输出。

## 小结

- 注意力机制能够将输入元素映射为**增强的上下文向量表示**，该表示融合了来自所有输入元素的信息。
- 自注意力机制通过对输入表示进行**加权求和**的方式来计算上下文向量。
- 在简化的注意力机制中，**注意力权重通常通过点积运算**计算得到。
- 点积是一种高效的计算方式，其定义为两个向量对应元素相乘并对乘积结果求和。
- 虽然注意力计算在理论上不依赖矩阵乘法，但在实际实现中，**矩阵乘法能够替代嵌套的 for 循环**，从而显著提升计算效率并使代码更加简洁。
- 在用于大语言模型的自注意力机制（亦称为**缩放点积注意力**）中，引入了**可训练的权重矩阵**，用于对输入进行中间变换，具体包括查询（Query）、键（Key）和值（Value）矩阵。
- 在从左到右读取和生成文本的大语言模型中，需要引入**因果注意力掩码（Causal Attention Mask）**，以防止模型在预测当前词元时访问未来的词元信息。
- 除了通过因果注意力掩码将部分注意力权重置为零之外，还可以引入 **Dropout 掩码**，以缓解大语言模型训练过程中的过拟合问题。
- 基于 Transformer 架构的大语言模型中，注意力模块通常包含多个并行的因果注意力实例，该结构被称为**多头注意力（Multi-Head Attention）**。
- 多头注意力模块可以通过**堆叠多个因果注意力模块实例**来构建。
- 更高效的多头注意力实现方式是利用**批量矩阵乘法（Batch Matrix Multiplication）**，以减少计算开销并提升并行计算能力。
