# 总结

![[image 1046.png]]

### 1. 指令微调的目标

- **指令微调（Instruction Tuning）** 的核心目标是：
> 将仅具备“续写能力”的预训练大语言模型，调整为能够理解人类指令并给出符合指令意图的回复。
- 与预训练阶段的“预测下一个词元”不同，指令微调强调**输入—输出的语义对齐**。

---

### 2. 数据集准备流程

指令微调数据通常以 **「指令 → 回复」** 的形式存在，完整流程包括：

1. 下载或构建指令-回复数据集
2. 统一数据格式（例如：instruction / input / output）
3. 划分数据集：
    - 训练集（train）
    - 验证集（validation）
    - 测试集（test）

本质上，这是一个**监督学习（Supervised Fine-Tuning, SFT）**问题。

---

### 3. 训练批次（Batch）构建方式

- 使用**自定义 collate function** 来构造 batch，而不是直接堆叠张量
- 该函数通常负责：
    - 对不同长度序列进行 **padding**
    - 构造 **目标词元 ID（labels）**
    - 对 padding 位置进行 **loss mask（忽略 padding 的损失）**

这是指令微调中非常关键的一步，否则模型会“学会预测 padding”。

---

### 4. 基础模型选择

- 以 **GPT-2 Medium（约 3.55 亿参数）** 作为指令微调的起始模型
- 原因：
    - 已具备语言建模能力
    - 规模适中，便于教学和实验
    - 架构稳定、易于复现

---

### 5. 微调训练方式

- 微调阶段的训练循环与预训练**在形式上高度一致**：
    - 前向传播
    - 计算交叉熵损失
    - 反向传播
    - 参数更新（如 AdamW）
- **本质区别不在训练代码，而在数据语义**：
    - 预训练：语言建模目标
    - 指令微调：指令—回复对齐目标

---

### 6. 模型评估方式

- 从测试集中抽取模型生成的回复
- 使用**自动化评分方法**进行评估，例如：
    - 让另一个更强的大语言模型对回复进行打分
- 最终以**平均分**等统计指标量化模型性能

## 二、你这段总结中需要澄清 / 修正的地方

### ❶ 关于 “Ollama + 80亿参数 LLaMA 评分”

> 原表述存在轻微误导，需要澄清

- **Ollama 本身不是模型**，而是一个本地模型运行与管理工具
- “80 亿参数的 LLaMA 模型”：
    - 指的是运行在 Ollama 中的某个 **LLaMA / LLaMA-派生模型**
    - 参数规模因具体模型版本而异（如 7B、8B）

✔ 更严谨的说法应为：

> 使用 Ollama 运行的某个大规模 LLaMA 系列模型，对微调模型的输出进行自动评分。

---

### ❷ “指令微调 ≠ 强化学习”

你的小结中**没有直接说错**，但需要明确一点：

- 这里描述的 **指令微调**：
    - 是 **监督微调（SFT）**
    - **不等同于 RLHF**
- 使用另一个模型“打分”：
    - 在这里**只是评估手段**
    - 并没有参与参数更新

很多初学者会把“模型打分”误以为是强化学习，这一点你需要刻意区分。

## 三、扩展理解（从“会背”到“会用”）

### 1. 指令微调在大模型训练体系中的位置

典型流程是：

```plain text
预训练（Pretraining）
        ↓
指令微调（SFT）
        ↓
偏好对齐（RLHF / DPO / PPO 等）

```

你当前学习的 **7.10** 处在**第二阶段**。

---

### 2. 为什么“训练代码几乎不变”却效果差异巨大？

这是一个非常关键的认知点：

- Transformer 架构、损失函数、优化器 **几乎完全相同**
- 真正改变模型行为的是：
    - 输入 prompt 的结构
    - label 的构造方式
    - loss mask 的设计

> 大模型训练的核心，不在“网络结构创新”，而在“任务定义”

---

### 3. 自动评分的现实意义

- 人工评估成本极高
- 使用强模型作为“裁判”：
    - 不能保证绝对客观
    - 但**在模型迭代对比中非常有用**
- 工业界常用：
    - LLM-as-a-Judge
    - Pairwise comparison

---

## 四、一句话压缩版

> 指令微调是利用指令-回复监督数据，对预训练语言模型进行 SFT，使其从“续写器”转变为“指令执行器”；其训练流程与预训练几乎一致，关键差异在于数据构造、loss mask 和评估方式，模型性能可通过更强的大语言模型进行自动化评分。
