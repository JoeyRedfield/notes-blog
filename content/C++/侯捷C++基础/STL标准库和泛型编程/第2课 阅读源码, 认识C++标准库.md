# deque

![[Untitled 664.png]]

注意和vector的容量扩充的区别. deque要实现双向的扩充. 

buffer的iterator的cur和first指向两端边界, 主要是为了连续性(假象). 它们位置不变, 只有cur会移动.

## deque如何模拟连续空间

![[Untitled 669.png]]

要知道start和finish都是迭代器. 

![[Untitled 670.png]]

考虑到了同一buffer和跨buffer的情况. 

node - x.node - 1是map中的距离.  按图中来看, 有内容的buffer有4行, 而完整buffer占3行, difference_type(buffer_size()) = 8, 3*8=24个buffer. 

加上两个迭代器所在的缓冲区有多少个buffer. 

感觉有点怪怪的, 但是实际上要注意node是map_pointer, 即T**类型, 而native pointer的减算由编译器实现, 算出来的是两个指针之间的距离. 以finish - start;为例, 实际上就是算的map中start和finish之间的距离. 按上图来说, 就是5 - 1 - 1 = 3.
