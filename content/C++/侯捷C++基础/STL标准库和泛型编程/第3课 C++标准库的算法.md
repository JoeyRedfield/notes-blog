# 函数适配器: binder2nd

![[Untitled 734.png]]

用的是右上角很古早的案例. 允许绑定第二个参数为40. 

`typename`关键字表示`Operation::second_argument_type`是一个**类型名**而不是一个变量名。

注意bind2nd()和binder2nd()是不一样的. 

编译器会推导Operation的类型. 

Operation::second_argument_type算是在问问题, 问arg2_type类型是什么. 然后执行arg2_type(x)能不能转换, 如果不行就编译报错. 

注意pred(*first)最终会去执行的函数. 实际流程是把*first跟value作op()操作, 也就是使用了比较器less<int>(). 

`count_if(vi.begin(), vi.end(), not1(bind2nd(less<int>(), 40)))`参与对象是vi容器(存int型元素), not1和bind2nd函数, bind2nd(less<int>(), 40) 表示绑定了第二参数40, 以及比较器less<int>(), 让vi容器中每个int值都跟40作大小比较, not1则是对结果取反(negate), 也就是说统计了**容器中不小于40的int型元素的数量**.

```c++
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
int main() {
	vector<int> vi{1, 2, 3, 4, 5, 6, 7, 8, 9};
	cout << count_if(vi.begin(), vi.end(), not1(bind2nd(less<int>(), 1))); // 9
	return 0;
}
```

## inserter

![[Untitled 739.png]]

上面的案例中, 第一个copy是不会管你越界与否, myvec越界直接报错. 

```c++
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>

using namespace std;

int main() {
	int myints[] = { 1,2,3,4,5,6,7,8 };
	vector<int> myvec(8);
	auto b = myvec.begin() + 2; // 迭代器往前走两步, 制造越界
	copy(myints, myints + 8, b);
	for (auto i : myvec) {
		cout << i << " ";
	}
	return 0;
}
// VS2022报错: Expression: cannot seek vector iterator after end
```

inserter是创造空间插入数据, 跟assign是不一样的. 而第一和第二案例用的是同一个copy函数但传进去的OutputIterator类型不一样, 设计上体现了C++操作符重载的妙处. 后者接管(重载)了assign操作.

## istream_iterator

![[Untitled 741.png]]

eos没赋值, 代表结束符号. ++*this进入到操作符重载 → 如果in_stream非空且在等待输入值, 有值输入后结果为true, 然后取反为false, 这样就不会重置in_stream=0. **如果输入非double类型数据也会置0**. 

++iit前置运算符, 用的一样是operator++(). 

![[Untitled 742.png]]

这里实现的是把读入的数据复制到容器中. 用inserter避免越界报错. 

注意, **在创建iit对象的时候, 就已经在等待读(cin)数据了**. 两个例子都是.

然后++iit和++first是一个意思, 等待下个数据. 

```c++
void t3() {
	vector<int> c;
	istream_iterator<int> iit(cin), eos;
	copy(iit, eos, inserter(c, c.begin()));
	for (auto i : c) {
		cout << i << " ";
	}
}

int main() {
	t3();
	return 0;
}
// 1 2 3 4 5 6 7
// a
// 1 2 3 4 5 6 7

// 这里输入a(非int值)是为了跳出cin, 也是为了证实上面的说法.
```
