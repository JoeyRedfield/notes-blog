# 容器 - 结构与分类

图示就是容器的分类和结构, 可以先想一下怎样实现这些容器: 

![[Untitled 594.png]]

- sequence containers就是常见的线性容器. 
    - Array是把语言的数组包装成一个class, 跟一般的array略有不同. 
    - Vector类也叫向量, 像是可变长度的数组.
    - Deque双向队列, 两端都可进可出
    - List是链表, 标准库提供的是双向环状链表
    - Forward-List (since C++11), 单向链表, 性能上比List会好一些. 
- associative containers(关联式容器)是可以快速查找元素的容器. 
    - Set集合, kv不分, elem不能重复
    - Map图, key-value结构, key不能重复
    - 带Multi就表示elem/key可以重复. 
    - 实际上上面两种在标准库里面并没有说明要用什么来实现, 但是由于红黑树性能很好, 所以各家编译器所带的标准库都用红黑树来做. 
        - 是特殊的二分树, 可以说是高度平衡的二分树. 
- unordered containers是C++11出现的新容器, 也是一种ac. 底部使用hash table做的. 里面的元素没有定性的排列. hashtable目前最好的碰撞处理就是图中的hashtable separate chaining. 每个pocket里面都是一条chain. 
    - 但是这样一来就要处理chain过长的问题. 也是数据结构课程中提到过的.

## 代码

![[Untitled 617.png]]

**我们的工具是容器, 没有太大必要去特地使用分配器调内存.** 实际上就是allocate和deallocate函数.

![[Untitled 618.png]]

我们平时使用到malloc和free函数, 把pointer交给free时我们不需要知道会释放多大内存, 但如果你手动记忆每个pointer要还多少就非常麻烦. 而使用allocate和deallocate就是这个道理. 就正常用new和delete的组合就行了.
