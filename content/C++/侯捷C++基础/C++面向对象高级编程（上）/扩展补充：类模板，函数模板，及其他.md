## 把ctors放在private区域

![[Untitled 520.png]]

实际上，`static A a`可以放到`private`区域，但是那样的话，没人调用`A`的时候就浪费空间了。这里优化思路是放到对外窗口`getInstance()`，在调用的时候才会初始化`static A a`。

# 模板

## class template，类模板

![[Untitled 522.png]]

第一行就是告诉编译器，`T`不知道是什么类型。

## function template，函数模板

![[Untitled 523.png]]

引数推导，简单来说就是把`T`替换掉。

图示就是案例：比大小。
所有的比大小都是通过`b < a ? b : a`来进行，所以通过操作符重载来实现比大小。但是必须要告诉编译器，`class`未确定。

这种把责任分开的设计是非常好的。
