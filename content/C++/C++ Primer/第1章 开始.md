自己实现：输入多个数字并统计出现次数

```c++
#include <iostream>
// 自己实现：输入多个数字并统计出现次数
int main() {
	int currval = 0, val = 0;
	if (std::cin >> currval) {
		// 确保有数据
		int cnt = 1; // 用于统计数字出现次数
		val = currval; // 入口
		while (std::cin >> currval) {
			// 这时候是第二个数字了，可以进行比较
			if (val == currval) {
				cnt++;
			}
			else {
				// 输出结果，初始化val和cnt
				std::cout << val << " occurs " << cnt << " times. " << std::endl;
				val = currval;
				cnt = 1;
			}
		}
		// 这里需要打印文件中最后一个值的个数，不写的话程序不终止，也无法输出
		std::cout << currval << " occurs " << cnt << " times" << std::endl;
	}
	return 0;
}
```

# 1.5.2节练习

```c++
// 练习1.23：编写程序，读取多条销售记录，并统计每个ISBN(每本书)有几条销售记录。
void practice1_23() {
	Sales_item currBook, preBook;
	if (std::cin >> preBook) {
		int cnt = 1;
		while (std::cin >> currBook) {
			// 第一次进入时，就拿到了第一和第二条数据
			if (preBook.isbn() == currBook.isbn()) {
				// 相同就加一
				cnt++;
			}
			else {
				// 不同就输出且初始化cnt和preBook
				std::cout << preBook.isbn() << " occurs " << cnt << " times." << std::endl;
				preBook = currBook;
				cnt = 1;
			}
			std::cout << currBook << std::endl;
		}
		// std::cout << currBook.isbn() << " occurs " << cnt << " times." << std::endl;
		std::cout << preBook.isbn() << " occurs " << cnt << " times." << std::endl;
	}
}
```


练习1.24：输入表示多个ISBN的多条销售记录来测试上一个程序，每个ISBN的记录应该聚在一起。

![[Untitled 85.png]]

> 这段代码会读入一系列的 Sales_item 对象，并根据每个对象的 ISBN 号进行分类汇总。其中，如果相邻的两个对象的 ISBN 号不相同，则输出之前的相邻对象的数量，并将计数变量重置为1，并且将当前的对象作为下一轮的起点。

最后一行代码 `std::cout << currBook.isbn() << " occurs " << cnt << " times." << std::endl;` 的输出结果为最后一个输入对象的 ISBN 号和数量，而倒数第二行代码 `std::cout << preBook.isbn() << " occurs " << cnt << " times." << std::endl;` 的输出结果为最后一个相邻的 ISBN 号和数量。**这是因为在处理最后一个输入对象时，虽然对象已经被读入，但是循环条件检查的是输入流的状态，即 **`**std::cin >> currBook**`** 语句会返回 false，循环内部的语句没有执行，此时的 currBook 对象还是默认构造出来的对象，即其 ISBN 号为默认值，而 preBook 对象则是最后一次作为起点的对象，两者不同**。

## 知识更新

**:: 运算符**( :: operator)作用域运算符。其用处之一是访问命名空间中的名字。例如，
std::cout表示命名空间std中的名字cout。

**<<运算符**（<<operator）输出运算符。将右侧运算对象的值写到左侧运算对象表示的输出流：cout<<”hi”表示将hi写到标准输出。输出运算符可以连接：cout<<”hi”<<”bye”表示讲输出hibye。

**>>运算符**（>>operator）输入运算符。从左侧运算对象所指定的输入流读取数据，存入右侧运算对象中：cin>>i表示从标准输入读取下一个值，存入i中。输入运算符可以连接：cin>>i>>j表示先读取一个值存入i，再读取一个值存入j。
