```plain text
【解答】

空语句是最简单的语句，空语句由一个单独的分号构成。如果在程序的某个地方，语法上需要一条语句但是逻辑上不需要，此时应该使用空语句，空语句什么也不做。

一种常见的情况是，当循环的全部工作在条件部分就可以完成时，我们通常会用到空语句。使用空语句时最好加上注释，从而令代码的阅读者知道这条语句是有意省略内容的。
```

5.2 

```plain text
【出题思路】

理解块的形式和用法。

【解答】

块是指用花括号括起来的语句和声明的序列，也称为复合语句。一个块就是一个作用域，在块中引入的名字只能在块内部以及嵌套在块中的子块里访问。如果在程序的某个地方，语法上需要一条语句，但是逻辑上需要多条语句，此时应该使用块。块不需要以分号结束。

例如，循环体必须是一条语句，但是我们通常需要在循环体内做很多事情，此时就应该把多条语句用花括号括起来，从而把语句序列转换成块。
```

5.3

```plain text
【出题思路】

使用连续的逗号运算符可以把多条语句合并为一条，这一点与块的作用类似。但是一般来说，直接使用块在程序的可读性上更有优势。

【解答】

原文的 while 循环使用了块，其形式是：

while (val <= 10) {
    sum += val;
    ++val;
}
利用逗号运算符改写之后的形式如下所示：

while (val <= 10)
    sum += val, ++val;
很明显，改写之后的代码不够清晰，可读性降低了。
```

练习5.8：什么是“悬垂else”？C++语言是如何处理else子句的？

悬垂else是说不用花括号而用缩进去对齐对应的if-else语句. C++语言按照最近匹配原则处理else子句. 

```plain text
【解答】

悬垂 else 是指程序中的 if 分支多于 else 分支时，如何为 else 寻找与之匹配的 if 分支的问题。

C++ 规定，else 与离它最近的尚未匹配的 if 匹配，从而消除了二义性。
```

### 5.4.1节练习

```c++
void practice5_14() {
	string prev = "", curr = "", res = "";
	int count1 = 0, c1 = 0; // count1用于记录当前字符串重复次数，c1记录最大次数
	while (cin >> curr && curr != "#") {
		if (prev == "") {
			// 只有第一次才会进入这里，可以用do-while去优化
			prev = curr;
			count1++;
			continue;
		}
		else {
			// prev已经有记录，跟curr比
			if (prev == curr) {
				// 相等就+1
				count1++;
			}
			else {
				// 不相等就说明遇上不同的字符串了，
				// 此时先比对当前count和c1谁大
				if (c1 < count1) {
					res = prev;
					c1 = count1;
				}
				// c1 > count1就不用处理c1和res了，这俩是记录最大次数和对应字符串，
				// 但换了字符串还是要初始化count1的
				prev = curr;
				count1 = 1; 
			}
		}
	}
	// 还需要处理while最后两个单词重复的时候，没有处理最大数的问题。
	if (c1 < count1) {
		res = prev;
		c1 = count1;
	}
	if (c1 == 1) {
		// 如果最大的count数是1，就说明任何单词都没有连续出现过
		cout << "任何单词都没有连续出现过" << endl;
	}
	else {
		cout << res << " " << c1;
	}
}
```

```c++
void practice5_25() {
	int i, j;
	char c;
	do {
		cin >> i >> j;
		try {
			if (j == 0) {
				throw runtime_error("除数不能为0");
			}
			cout << i / j << endl;
		}
		catch (runtime_error re) {
			cerr << re.what() << endl;
			cout << "是否要重新输入?";
			cin >> c;
		}
	} while (c != 'n');
}
```
