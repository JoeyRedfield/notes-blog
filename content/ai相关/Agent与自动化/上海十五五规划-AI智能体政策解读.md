# 上海"十五五"规划：AI 智能体政策解读

## 政策要点

2026 年 6 月 1 日，上海市人民政府办公厅印发《上海市服务业发展"十五五"规划》，在"前瞻布局服务新兴赛道"章节中，**首次将 AI 智能体列为服务业重点发展方向**。

核心表述：

> **AI 智能体**：支持多模态智能体开发与应用，推动智能客服、智能运营、智能决策等工具规模化应用。

## 政策定位

AI 智能体属于规划第四部分"前瞻布局服务新兴赛道 → 深化发展智能技术类新服务"的八个方向之一，同级方向包括：

| 方向 | 要点 |
|------|------|
| AI 软件技术及服务 | 生成式 AI，聚焦人脸/图像识别、AR/VR、智能交通、智慧物流 |
| AI+ 研发 | 生物医药、新材料、新能源 |
| 具身智能服务 | 家庭/养老/文旅/商业场景整机产品 |
| 智算云服务 | 算运存协同智算云网络，推广 MaaS |
| 云平台服务 | 金融/医疗/文旅垂直领域"AI+"标杆 |
| **AI 智能体** | 多模态智能体开发与应用，智能客服/运营/决策规模化 |
| 智能驾驶 | 共享出行、物流运输多场景应用 |
| 智能家居 | 全方位感知、智能化控制，养老/育儿/办公/娱乐 |

## 关键信号

1. **多模态是明确方向**：政策不再只说"AI"或"大模型"，而是精确到"多模态智能体"，说明决策层对技术路线的认知在细化
2. **规模化应用是考核点**：强调"规模化应用"，意味着政策将推动从实验性部署走向生产级落地
3. **三个应用切口**：智能客服（前台交互）、智能运营（中台流程）、智能决策（后台分析）——覆盖企业全价值链
4. **不是孤立条目**：AI 智能体与具身智能、智能驾驶、智算云形成完整拼图——智算云提供算力基础设施，具身智能是物理世界载体，智能驾驶是垂直场景，AI 智能体是软件层面的统一范式

## 产业影响

- **To B 服务市场加速**：政策明确推动智能客服/运营/决策工具，企业级 AI Agent 采购需求将受政策激励
- **上海本地生态受益**：规划提出"打造 AI 软件技术及服务产业集群"，上海本地的 AI Agent 创业公司和平台将获得政策倾斜
- **与智能驾驶的联动**：智能驾驶有序推进共享出行和物流运输，这些场景中的调度、客服、决策系统天然适合 AI Agent 落地
- **MaaS 降低门槛**：规划推广模型即服务（MaaS），中小企业的 Agent 开发门槛将降低

## 规划整体背景

- 目标：到 2030 年，服务业增加值达到 **6 万亿元**左右
- 空间布局："一核、两翼、三带、多片区"（1+2+3+N）
- AI 智能体是 8 个智能技术新兴赛道之一，同时与信息服务（软件研发、在线新经济）、工业服务（数字化转型服务商）等传统章节形成交叉支撑
